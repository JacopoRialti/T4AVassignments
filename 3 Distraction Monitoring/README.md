# Distraction Monitoring System (DMS)

A computer vision-based application designed to monitor user distraction in real-time.

## Prerequisites

Before running the program, ensure you have Python installed. It is recommended to use a virtual environment.

### 1. Installation

Install the required dependencies using `pip`:

```bash
pip install -r requirements.txt
```

*Note: The project requires `opencv-contrib-python`, `mediapipe`, `numpy`, `scikit-learn`, and `scipy`.*

## Running the Application

To start the Distraction Monitoring System, run the following command in your terminal:

```bash
python runDMS.py
```

## How to Exit

To close the video window and terminate the program:
* Press the **`ESC`** key on your keyboard while the application window is focused.
